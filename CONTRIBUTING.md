# Contributing

Thanks for helping make 1-on-1s better for everyone.

- Open an issue before large changes so we can agree on direction.
- Keep the product org-agnostic: no HR-, government-, or industry-specific wording.
- Every new table needs row-level security. Private notes must never become visible to anyone but their author, and must never be sent to AI.
- Use the semantic color tokens in `src/styles.css`; don't hardcode colors.
- Keep AI optional: every feature must work with AI turned off.

By contributing you agree your work is released under the MIT license.
